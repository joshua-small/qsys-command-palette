Command Palette 0.1.0

Open with Ctrl+Shift+P or Tools > Q-SYS Mods > Command Palette.
Search native and registered mod commands by name, category, source, or shortcut.
Use fuzzy abbreviations, arrow keys, Page Up/Down, Enter, Escape, or double-click.
See effective shortcuts, unavailable commands, and recent choices for this session.
Commands execute after restoring and rechecking the original editor context.

Requires Q-SYS Mods Core 0.1.4 and the exact supported Designer 10.5 build.
Main-window entry only; floating windows and embedded browser keyboard handling
are not accepted. Better Shortcuts is optional.

Install through Q-SYS Mod Manager 0.8 or newer after refreshing its signed catalog.
